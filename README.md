# Harrison & Loft — Cognitive Assessment Platform

A responsive bilingual (English/Spanish) front-end starter built with React + Vite.

## Included
- English / Spanish interface switch
- Responsive dashboard inspired by the supplied reference
- Memory, attention, reading and visual perception activities
- Automatic scoring for demo activities
- Assessment history and printable report view
- Local browser storage for demo profile and results
- Supplied brand and assessment images in `public/images`

## Run locally
1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown in the terminal.

## Build
Run `npm run build`. Vite writes the production site to `dist`.

## Deploy to Vercel
1. Upload this project to a GitHub repository.
2. In Vercel choose **Add New → Project** and import the repository.
3. Framework preset: **Vite** (usually detected automatically).
4. Build command: `npm run build`
5. Output directory: `dist`
6. Deploy.

## Important clinical and privacy note
This starter contains educational/demo cognitive activities, not validated psychometric instruments. Scores are illustrative and must not be used to diagnose, screen, hire, treat, or make clinical decisions. Before real clinical use, have qualified professionals select/validate instruments, establish norms and protocols, and review consent, accessibility, data retention, security, and applicable privacy requirements. Demo results are stored only in the current browser via localStorage; there is no secure account system or server database.

## Image quality
The supplied images are included in `public/images`. Some originals were small and were enlarged for layout use; enlargement cannot restore details that were not present in the source files. Replace with high-resolution originals for true HD hero imagery.
